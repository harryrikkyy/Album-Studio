# Quality evidence

Each dated folder holds one quality iteration's summary and its smaller result files. On
2026-10-28, raw logs and result files over 100 KB moved to the evidence archive; see
[ARCHIVE.md](ARCHIVE.md). The iteration READMEs still name files that now live only in the
archive, at the same relative path. Those READMEs stay byte-identical because later
`verification.json` files record their checksums. Earlier logs, the scorecard and planning notes
are in [archive/](archive/); current status is on [the status page](../../QUALITY_IMPROVEMENT_LOG.md).
